# Интернет-магазин светильников

Проект для демонстрации каталога товаров с фильтрацией, сортировкой, корзиной (localStorage) и пагинацией.

## Технологии
- Vanilla JavaScript (чистый JS)
- Swiper.js для слайдера
- Tippy.js для подсказок

## Как запустить
1. Клонируйте репозиторий
2. Установите расширение **Live Server** для VS Code
3. Откройте файл `catalog.html` и запустите **Live Server** (Alt+L, Alt+O)

или

2. Используйте любой локальный сервер, например:
   ```bash
   npx serve .
